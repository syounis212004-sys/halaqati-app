# Halaqati v2.46.3-RC11.3 — Unified Phase Control & Stability

هذا الإصدار يبني فوق RC11.2 ويعيد إدارة دورة الحفظ والسرد إلى تصور RC11 الأصلي: إدارة جماعية للحلقة أولاً، ثم تخصيص الطالب عند الحاجة.

## الإدارة الجماعية
- شاشة واحدة تعرض مرحلتي الحفظ والسرد لكل طالب في مسار الحفظ العام.
- اختيار بداية ونهاية الحفظ وبداية ونهاية السرد بصورة موحدة.
- هدف سرد موحد افتراضياً 25 صفحة واتجاه افتراضي من الناس إلى البقرة.
- اختيار أيام السرد كاملة بالأسماء.
- تحديد جميع الطلاب أو استثناء أي طالب.
- تخصيص مستقل لكل طالب للتواريخ وهدف السرد والاتجاه وأيام السرد.
- الخطط القديمة التي لا تحتوي phases تُنشأ لها مرحلتا الحفظ والسرد داخل العملية الجماعية دون تغيير هدف الحفظ الفردي.

## إصلاحات الاستقرار
- تمرير اتجاه السرد من phase إلى مولد المقرر فعلياً.
- منع احتساب generic test كسرد أو تحريكه لـ Sard Anchor.
- نهاية اتجاه الناس→البقرة عند البقرة لا الفاتحة.
- منع إنشاء جلسة تلقائية وهمية يوم السبت؛ الجلسة الاستثنائية تبقى يدوية وصريحة.
- Dashboard يعتمد المرحلة الفعلية بدلاً من الخطة الأم عند تحديد نشاط اليوم.
- تسلسل RPC/Outbox ومنع تكرار الإرسال بعد نجاح الطلب.
- عدم بدء مرحلة سرد مستقبلية أو إرسال phase_started قبل تاريخها.
- توحيد قاعدة البيانات على مسارين فقط: general_hifz و tathbit؛ السرد activity/phase فقط.
- backfill آمن للـ phase_id فقط عندما يوجد مالك واحد واضح للتسميع القديم.
