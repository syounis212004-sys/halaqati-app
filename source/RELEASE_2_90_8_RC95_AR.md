# RC95 (2.90.8): هوية موحّدة لكل الأدوار

يتضمن تغييرات RC94 (لم يُنشر لأن فحص APK توقع رقم الإصدار القديم في ملف البناء).

- واجهة رئيسية موحّدة لكل الأدوار: تدرّج أخضر عميق مع نقش هندسي واحد (المدير، المشرف، المحفّظ، وليّ الأمر، المانح، الإعدادات، الهيكل).
- زخرفة صغيرة موحّدة: نجمة ثمانية ذهبية قبل عناوين الأقسام.
- الأرقام الكبيرة بخط Cairo بدل Amiri.
- حقول الاختيار بنفس شكل حقول النص؛ نموذج الزيارة: تقييم 1–5 بخمسة أجزاء متساوية وصف «المحفّظ حاضر» واضح.
- التقارير: لا صفحة بيضاء فارغة قبل التجهيز، وقسم «التصدير والمشاركة».
- الإعدادات: صورة الحساب في الترويسة، والخيارات لا تُقص.
- الإشعارات، محادثات المانحين، الكادر، الهيكل، الشهادات، ترتيب وليّ الأمر: شارات هادئة بدل الدوائر المصمتة.
- صور الطلاب للمشرف والمدير: تُجلب على دفعات أصغر مع إعادة محاولة.
- أحجام الأيقونات موحّدة (20/24/28).
- لا تغيير في الوظائف أو الصلاحيات أو البيانات.
