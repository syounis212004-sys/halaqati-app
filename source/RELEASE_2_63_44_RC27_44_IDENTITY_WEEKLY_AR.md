# RC27.44 — تعبئة الهوية وملخص الأسبوع (2.63.44 / 26344)

- شاشة طلبات الاعتماد: قسم لتعبئة رقم الهوية وتاريخ الميلاد للطلاب النشطين الناقصين (حفظ فردي عبر نفس مسار تعديل الطالب).
- ولي الأمر: بطاقة ملخص آخر 7 أيام (أيام التسميع، العدد، الصفحات، الجودة) مع مشاركة، محسوبة من آخر التسميعات المعروضة.
- أرشيف الشهادات: لا يصبح فارغًا عند فشل التحديث، وتظهر رسالة.
- لا حاجة لأي SQL جديد.
