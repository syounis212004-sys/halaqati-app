# حلقتي 2.85.0 — RC49: التحويل الموثّق وصفحات المانح

- **الدفع:** حساب افتراضي (بنك/محفظة) قابل للتعديل، أو حساب لكل بطاقة. المبلغ رقمي بالشيكل/الدولار/الدينار الأردني.
- **المانح:** بيانات التحويل مع نسخ، ثم رقم الحوالة أو صورة الإشعار. المدير يتحقق ويؤكد ثم يوثّق التسليم برسالة شكر.
- **الأرقام:** السلوك والجودة والسرد والحضور ≤ 100٪؛ الحفظ فقط يتجاوز مع «تجاوز الخطة».
- **صفحات المانح:** تبويبات مقسّمة، «أثري» (أثر، شارات، تقرير الشهر، سجل، أخبار، اقتراحات)، «كافئ هذا الطالب».
- **المدير:** تبويب أخبار واقتراحات في «الدعم والمانحون».
