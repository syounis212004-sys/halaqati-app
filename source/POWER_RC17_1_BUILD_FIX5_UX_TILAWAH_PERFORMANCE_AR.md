# RC17.1 BUILD FIX 5 — UX / Tilawah / Selector Performance

هذا التحديث يجمع تحسينات الأداء والواجهة ونظام التلاوة بدون تغيير مخطط قاعدة البيانات.

## ما تغير

- استبدال قوائم الاختيار الطويلة بمحدد موحد Lazy/Searchable مبني على `LazyColumn`، بما في ذلك الآيات والسور والطلاب والفلاتر الطويلة.
- منع تكسير أسماء الأيام والخيارات العربية إلى عدة أسطر عبر `ResponsiveChipGrid` وChips أحادية السطر.
- الفصل بين «تعديل بيانات الخطة» و«إدارة مراحل الحفظ والسرد»؛ تعديل بيانات الخطة لا يفتح شاشة المراحل.
- إبقاء اسم الخطة والسياسات العامة قابلة للتعديل، بينما أهداف/تواريخ/نطاقات المراحل تعدل من شاشة المراحل.
- ضغط بطاقات المراحل وعرض التفاصيل الطويلة في سطر واحد مع Ellipsis بدل التفاف مزعج.
- إضافة تقييم تلاوة يدوي مستقل عن الحفظ: لحن جلي/خفي، مخارج وصفات، تجويد، وقف وابتداء، طلاقة وترتيل، رواية، ونقاط متابعة.
- تخزين تقييم التلاوة داخل `selection_data.tilawah_assessment` الموجودة أصلًا؛ لذلك لا يحتاج هذا التحديث Migration جديدة.
- التلاوة لا ترتبط تلقائيًا بخطة حفظ/تثبيت ولا تحرك Anchor الخطة.
- السماح بتقييم التلاوة لطلاب الحفظ العام وطلاب التثبيت بدون إظهار حفظ/سرد لطلاب التثبيت.
- تحديث هوية تسجيل الدخول وSplash/App Icon بهوية الشرقية — خانيونس، مع حركة دخول خفيفة والنص:
  - `صُنع بأيدٍ شرقية`
  - `Designed by : Dr. Mohammed Samir Abu Younis`

## مبدأ الأداء

فتح قائمة اختيار لا يجب أن ينشئ مئات العناصر دفعة واحدة أو يشغّل Query شبكيًا. البيانات الكبيرة تظهر داخل `LazyColumn` وتبنى الصفوف المرئية فقط.
