# RC17.1 — Consistency, Smart Plan & Performance Patch

باتش واحد فوق RC17/New UI يحافظ على كل منطق التطبيق وSupabase والتقارير والشهادات والأوفلاين.

## ما تغير
- فصل إنجاز **الحفظ** عن **السرد** في لوحة ولي الأمر. لا يُعرض مجموعهما كأنه رقم حفظ واحد.
- الخطة تعرض كل نشاط بهدفه/منجزه/متبقيه؛ شريط التقدم يتوقف بصريًا عند 100% ويظهر الإنجاز الزائد منفصلًا.
- RPC جديد بديل `guardian_child_overview` يعيد `plan.activities` وحالة جلسة اليوم، مع fallback في التطبيق حتى قبل تطبيق الـmigration.
- حالات اليوم تفرق بين: لا توجد جلسة / الجلسة لم تبدأ / لم يسجل الحضور / غائب / حضر ولم يسمع / سمع.
- تدقيق RTL: عنوان الشاشة والـkicker والـheroes على Start (يمين العربية) والأفعال الرئيسية أيضًا semantic Start.
- رفع تباين Dark Mode وحماية الألوان المخصصة منخفضة السطوع.
- Typography هرمية: عناوين وأسماء أوضح، معلومات مساعدة أخف.
- زر مباشر **تعديل الخطة الذكية** بعد الإنشاء؛ الخطة ذات المراحل تفتح محرر المراحل الحقيقي بدل محرر مقفل.
- الطالب الموقوف/غير النشط لا يدخل قوائم جلسات اليوم أو roster التسميع، ولا يدخل مؤشرات التشغيل اليومية؛ يبقى في الإدارة والسجل لإعادة التفعيل.
- تحسين cold start: WorkManager يُجهز خارج Main Thread، ولوحة المتابعة تعرض cache أولًا ثم تجدد الشبكة.
- Bottom Navigation بحركة خفيفة، Splash/branding غير حاجب، Adaptive launcher icon لأندرويد الحديث.
