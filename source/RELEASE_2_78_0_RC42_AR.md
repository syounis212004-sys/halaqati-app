# حلقتي 2.78.0 — RC42

- سجل التسميعات جدول (طالب × أيام) بصفحات من 6–7 أيام، مع إجمالي، وتصدير Excel/Word بنفس الشكل.
- زر «＋» قائمة إضافة سريعة بدل التنقل.
- شعار المركز/الحلقة لكل حساب (لا يظهر شعار المدير لغيره).
- المراقب: إصلاح الفصل + تفاصيل الطالب.
- صفحة «المتابعة والمقارنة» مع تذكّر آخر نتيجة.
