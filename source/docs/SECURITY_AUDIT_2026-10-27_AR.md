# فحص الصلاحيات قبل الإطلاق — 27 أكتوبر 2026

فحص للقراءة فقط على مشروع Supabase الإنتاجي (بلا أي تعديل). لا يتضمن هذا الملف أسماء أو معرّفات مستخدمين.

## اختبار نطاق الرؤية (RLS)
جُرّب بمحاكاة كل نوع حساب داخل معاملة تُلغى:
- **محفّظ:** يرى طلاب حلقته فقط (25 أو 53 من 64) وتسميعاتهم فقط.
- **ولي أمر:** يرى طفله أو طفليه فقط (1–2 طالب) وتسميعاتهم فقط.
- **مشرف/مدير:** يرى نطاق إشرافه (حتى 64 طالبًا).
النتيجة: لا تسرّب بين الحلقات أو بين أولياء الأمور في الطلاب والتسميع.

## تنبيهات المنصّة (Supabase advisors)
- 63 دالة SECURITY DEFINER قابلة للتنفيذ من المستخدم المسجّل: هذا نمط التطبيق (RPC). فُحصت الدوال الحساسة (حذف حساب، حذف حلقة، بدء الشهر، إعادة الربط، الشهادات، الاعتماد): كلها تتحقق من الدور داخليًا. دالتا `rc19_start_month` و`rc18_start_month` تستدعيان دوالًا محمية. `rc152_tathbit_consistency` تعيد أعدادًا مجمّعة فقط.
- حماية كلمات المرور المسرّبة غير مفعّلة: **فعّلها من لوحة Supabase** (Authentication ← Password security).
- ثلاثة جداول بلا سياسات (`certificate_number_counters`, `halaqati_internal_secrets`, `rc_link_attempts`): مقصود (رفض كل الوصول المباشر).

## ما لم يُفحص
- حساب بدور «مشرف» محدود النطاق (يوجد مشرفان فقط بنطاقات متقاربة).
- محاولات تجاوز عبر استدعاء REST مباشر لكل جدول.
