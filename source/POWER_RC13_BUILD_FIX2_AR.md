# RC13 BUILD FIX2 — PDF selectable Arabic gate stability

## سبب الإصلاح
نجحت بوابات RC13 المصدرية في GitHub، ثم فشل فحص PDF المرئي لأن pypdf على بيئة GitHub أعاد النص العربي بتقسيم/ترتيب glyph runs مختلف عن البيئة المحلية، ففشل التطابق الحرفي لعبارة اسم الطالب رغم أن PDF نفسه بقي متجهيًا وقابلًا للتحديد.

## ما تغير
- لا تغيير في محرك الشهادات أو التقارير أو Kotlin أو Supabase.
- جعل فحص selectable Arabic دلاليًا ومقاومًا لاختلافات Presentation Forms / bidi / التشكيل / المسافات.
- إبقاء فحص رقم الشهادة اللاتيني صارمًا بعد تطبيع الفواصل.
- إضافة حد أدنى حقيقي لكمية النص العربي المستخرج حتى لا ينجح PDF raster-only بالخطأ.
- إضافة فحوص مصدرية تمنع الرجوع إلى التطابق العربي الحرفي الهش.

## النطاق
التغيير محصور في:
1. scripts/rc13-render-fixtures.py
2. scripts/rc13-document-reports-check.py
3. هذا المستند التوثيقي.

الإصدار التطبيقي يبقى 2.48.0-RC13 / versionCode 24800.
