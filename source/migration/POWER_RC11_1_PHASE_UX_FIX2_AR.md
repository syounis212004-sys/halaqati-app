# RC11.1 — Phase UX Fix 2

هذا التحديث يحافظ على مساري الطالب فقط: `general_hifz` و`tathbit`. السرد نشاط/مرحلة داخل الخطة الذكية وليس مسارًا ثالثًا.

## ما تغير
- إعادة تصميم إدارة المراحل لتكون بطاقات رأسية متجاوبة بدل الأعمدة الضيقة التي تكسر العربية حرفًا حرفًا.
- إعادة بناء الانتقال الجماعي إلى السرد مع هدف سرد موحد افتراضي 25 صفحة، استثناء الطلاب، وتخصيص هدف سرد لطالب بعينه، مع تجميد هدف/إنجاز الحفظ الفردي كما هو.
- حقول بداية ونهاية المرحلة تفتح Material DatePicker حقيقيًا.
- عرض أسماء أيام الأسبوع كاملة.
- محرر المرحلة أصبح Dialog واسعًا قابلًا للتمرير، مع معاينة قبل الاعتماد.
- مرحلة السرد الجديدة: `pages + 25 + flexible + last_sard` افتراضيًا.
- عرض آخر Sard Anchor، نقطة البداية التالية، اتجاه القرآن، ومعاينة النطاق المتوقع قبل الحفظ.
- إضافة بحث للحلقة والطالب في محرر الخطة؛ الطالب يبقى مفلترًا حسب الحلقة المختارة.
- منع إنشاء عمليات مراحل جديدة عندما يكشف التطبيق أن جداول RC11 غير موجودة في PostgREST schema cache.
