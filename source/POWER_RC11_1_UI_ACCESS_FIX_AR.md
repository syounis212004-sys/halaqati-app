# RC11.1 — UI Access Fix

هذا الإصدار لا يغير محرك RC11؛ يثبت الوصول المرئي إلى وظائفه من شاشة الخطط الذكية.

- زر مباشر **مراحل الحفظ والسرد · RC11** أعلى شاشة الخطط.
- زر مباشر داخل بطاقة الطالب **إدارة مراحل الحفظ والسرد**.
- منتقي خطة واضح إذا كان هناك أكثر من خطة.
- عرض إجراءات الطلاب داخل المراحل افتراضيًا بدل إخفائها.
- زر صريح **إضافة السرد** عند غياب مرحلة السرد.
- تسمية النقل الجماعي أصبحت **إنهاء الحفظ وبدء السرد**.
- فتح محرر السرد مباشرة عند الضغط على **إضافة السرد**.
- versionCode=24613 و versionName=2.46.1-RC11.1 لتمييز APK المثبت.
