# RC17 Build Fix 1 — Role Navigation Unit-Test Sync

سبب فشل GitHub Actions لم يكن Compile أو Lint أو APK، بل اختبار قديم في `RoleNavigationPolicyTest`.

في RC17 أصبح شريط ولي الأمر السفلي مقصودًا أن يكون:
- الرئيسية
- ملف الطالب
- الإنجازات
- المزيد

بينما الاختبار القديم كان ما يزال يتوقع تخطيطًا سابقًا يضع التقارير والخطط في الشريط السفلي.

الإصلاح:
1. تحديث توقع الاختبار ليتطابق مع `RoleNavigationPolicy` المعتمد في RC17.
2. إبقاء اختبارات فصل المنافسة والإنجازات.
3. إضافة regression test يضمن بقاء `plans` و`reports` مسموحتين لولي الأمر، وأن `reports` متاحة من قسم المزيد، مع بقاء `plans` متاحة من التنقل المخصص/القائمة.

لم يتم تغيير منطق Supabase أو قاعدة البيانات أو واجهة RC17 بسبب هذا الإصلاح.
