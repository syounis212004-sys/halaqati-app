# Halaqati v2.48.0 — RC13 Document & Reports Studio

RC13 يعيد بناء مسار الشهادات والتقارير فوق النسخة Native Kotlin/Compose مع إبقاء v2.44 كـGolden Master للتصميم والسلوك، وليس كواجهة Web للتطبيق. التطبيق نفسه Native؛ WebView معزول داخل حزمة `documents` فقط ويُستخدم كمحرك محلي لإنشاء ومعاينة HTML/CSS ثم طباعته إلى PDF متجهي A4.

## لماذا تغيّر محرك PDF

المسار السابق كان يرسم الشهادة مباشرة عبر Android Canvas، ما جعل التخطيط حساسًا للإحداثيات الثابتة وأدى إلى تداخل النصوص وتضخم الصور داخل PDF. RC13 يوحّد المعاينة والتصدير في مستند واحد: `DocumentSpec/HTML -> Preview -> Chromium PrintAdapter -> A4 PDF`، لذلك لا توجد نسختان مختلفتان من التخطيط.

## الشهادات

- استعادة هوية v2.44: الإطار متعدد الطبقات، Girih خافت، الزوايا والوريدات، الشعاران، اسم المركز والحلقة، شارة نوع الشهادة، صندوق اسم الطالب، الإنجاز، الدعاء، التاريخان، المحفظ والمشرف والختم والآية ورقم الشهادة.
- القوالب والألوان والخطوط والأحجام والشعارات والإظهار/الإخفاء وموضع الرقم تبقى قابلة للتخصيص.
- Auto-fit يعتمد على قياس النص الحقيقي داخل DOM، وليس إحداثيات ثابتة.
- يوجد Layout Preflight قبل إنشاء PDF؛ أي خروج نص أو اصطدام بالمنطقة المحمية يفشل التصدير بدل إنتاج ملف معطوب.
- الصور تُصغّر وتُضغط محليًا قبل إدراجها؛ الشعار JPEG بالحجم المناسب، والتوقيع/الختم PNG عند الحاجة للشفافية.
- PDF والشعارات والتواقيع والختم تبقى محلية؛ Supabase يحتفظ ببيانات السجل/الرقم/Snapshot فقط.

## التقارير

استعادة الأنواع الستة من محرك v2.44 مع مصدر البيانات Native الحالي:

1. التقرير الشامل للحلقة.
2. لائحة الأوائل.
3. تقرير النقاط.
4. تقرير الحضور.
5. سجل التسميعات.
6. تقرير مستقل لكل طالب.

الفلاتر تشمل اليوم/الشهر/الفترة المخصصة، المسار، الحلقة ونوع اللقاء. عند اختيار جميع المسارات تُنشأ أقسام مستقلة للحفظ العام والتثبيت. يدعم الاستوديو الاتجاه، الخط والحجم، الألوان، الشعارات، الأعمدة الظاهرة، صور الطلاب وتاريخ الميلاد واسم المحفظ حيث ينطبق.

جداول PDF تستخدم `table-header-group` لتكرار الرأس و`break-inside: avoid` لتقليل قطع الصفوف، مع حساب تلقائي لعرض الأعمدة وتصغير أسماء الطلاب عند الحاجة.

## A4 وPDF

`VectorDocumentRenderer` يستخدم `PrintAttributes.MediaSize.ISO_A4` ولا يعتمد على أبعاد Canvas يدوية. المعاينة وPDF يستخدمان نفس HTML/CSS. WebView محلي مع تعطيل الشبكة، ولا توجد عودة إلى Capacitor أو Web runtime للتطبيق.

## Quality Gates

- Source/architecture gate لـRC13.
- جميع Regression gates من RC7 حتى RC12.
- 48-feature parity + release parity.
- Pure Kotlin self-tests لمحركات القرآن والخطة الذكية والأوفلاين والمصادقة والتعارضات.
- Browser fixture gate يولد شهادة عادية وشهادة Stress وتقريرًا من 40 طالبًا.
- فحص DOM layout قبل الطباعة.
- فحص A4 عبر `pdfinfo`.
- فحص أن الشهادة صفحة واحدة.
- حد حجم 3MB لشهادة الاختبار.
- فحص Arabic/selectable text عبر `pdftotext`.
- Render-to-PNG لفحص بصري حقيقي للشهادة والتقرير.
- CI لا يرفع APK إلا بعد Kotlin compile + unit tests + lint + assemble + هوية APK/التوقيع.

## قاعدة البيانات

لا توجد Migration جديدة لـRC13. يلزم أن تكون Migration RC12.1 مطبقة مسبقًا. RC13 لا ينفذ DDL حيًا أثناء بناء APK.
