# الإصدار 2.60.3 RC24.3 — واجهة مدمجة وتقليل المساحات الفارغة

- رأس الشاشة أصغر، ووُحّد ارتفاعه ولا ينمو بلا حاجة.
- شريطا "غير متصل" الأصفران استُبدلا بأيقونة اتصال صغيرة (سحابة مشطوبة / مزامنة) مع عدّاد للعمليات المعلقة؛ الضغط عليها يفتح مركز المزامنة.
- `CompactSearchField`: حقل بحث من سطر واحد بلا تسمية عائمة، ويُستخدم في الطلاب والخطط والإشعارات.
- رسالة بطاقة الرئيسية تتغير حسب الدور وحالة اليوم (`HomeMessages`) مع أيقونة، بدل العبارة الثابتة.
- ضغط ارتفاع الأسطر في الطباعة، وتقليل الهامش الأفقي إلى 14dp، وإزالة الحد الأدنى لبطاقة الحالة اليومية.
- شاشة الخطط الذكية: صف شهر واحد وحقل بحث واحد بدل كتل متعددة.
- الكثافة الافتراضية للتثبيتات الجديدة: مدمجة.
- لا SQL جديد. (يلزم تنفيذ SQL الإصدار RC24.1 مرة واحدة إن لم يُنفَّذ.)
